# Historical detector research

This directory preserves the repository's Apriori, matcher, vulnerability, and execution-pattern experiments at source commit `cc4ae68d38a9391c931d09c6786ded422a76cb6d`.

The source tree hash and original path are recorded in `PROVENANCE.json`. Current-tree private machine paths were replaced with `research-data`; this privacy edit does not rewrite Git history or recreate unavailable datasets. These programs have optional research dependencies and are not imported by the supported profiler.

The supported implementation lives in `smart_rule_analyzer/`. Passing its tests establishes the governed implementation only. It does not reproduce historical accuracy or experiments.
